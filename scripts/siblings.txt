# The sibling checkouts this repository builds and tests against, each at ONE pinned commit.
# test.sh places them beside the repository (scripts/siblings.sh clones a missing one) and refuses a
# sibling at any other commit; scripts/siblings.sh refuses an unpinned name, a short or symbolic
# commit, and a fetch source that is neither https://github.com/urnetwork/ nor one of the review
# sources it lists. Bump a pin in its own commit.
# name  url  commit
#
# THREE OF THESE PINS ARE PULL REQUEST HEADS, FETCHED FROM THE OWNER'S FORKS UNTIL THEY MERGE. This
# repository is one of a set: the removal of messaging from urnetwork/sdk, the removal from
# urnetwork/connect, this import, and message-server's switch to these packages. They are built and
# tested together, so each pins the others' heads, and those heads are on the forks the pull requests
# come from. The pin is the commit, which no fetch source can change. When a pull request has merged
# (with a merge commit, so its head keeps its id), switch that line's URL to the urnetwork
# repository named in its comment and delete the fork from scripts/siblings.sh's review sources;
# until then test.sh's verdict names each such sibling.
#

# connect and adds connect.NewOperatorClientSettings, which sdk/message_tunnel.go calls: branch
# upstream/remove-message of the fork, which merges urnetwork/connect main at 6df2fa87. A connect
# still carrying message.proto would register the schema twice in every binary here, which protobuf
# refuses at init. After the merge: https://github.com/urnetwork/connect.git.
